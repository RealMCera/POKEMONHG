# Pokémon: The First Movie — HGSS Base

This repository is the working base for a First Movie adaptation built on the public `pret/pokeheartgold` decompilation.

## Base
- Upstream: `pret/pokeheartgold`
- Target ROM: US Pokémon HeartGold
- Expected SHA-1: `4fcded0e2713dc03929845de631d0932ea2b5a37`
- Working branch: `first-movie`

## Direction
We are no longer rebuilding the DS engine from scratch. We will retain the HGSS field engine, map-object system, scripts, battles, menus, saves, transitions, text rendering, sprite system, and NitroFS layout, then replace the campaign/content layer with the First Movie campaign.

## Campaign
1. Mewtwo creation lab
2. Giovanni facility / controlled battles
3. Ash, Misty, and Brock introduction
4. invitation sequence
5. harbor and storm crossing
6. New Island arrival
7. grand hall and trainer gathering
8. Mewtwo reveal
9. clone trials
10. cloning lab
11. originals vs clones
12. Mew vs Mewtwo
13. finale
14. postgame New Island challenges

Do not commit retail ROMs or proprietary toolchains.
